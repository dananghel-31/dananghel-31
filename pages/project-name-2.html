Hospital Network

A networking project focused on routing, VLANs, subnetting, and network structure.

Project Details

This project was created in Cisco Packet Tracer to practice networking fundamentals and infrastructure design.

The project includes routers, switches, VLAN configuration, VLSM subnetting, and communication between networks with VPN and Firewalls.

Tools Used

  • Cisco Packet Tracer
